## 3. 다음 작업 — Python 미탐 원인

### 확인된 사실

최소 재현으로 좁혔고, 아래 네 가지가 **전부 미탐**이다:

```python
from flask import request
import codecs

bar = request.cookies.get('x')
codecs.open(bar, 'r')            # 미탐
codecs.open(f'/tmp/{bar}', 'r')  # 미탐
open('/tmp/' + bar, 'r')         # 미탐
open(f'/tmp/{bar}', 'r')         # 미탐
```

규칙에는 소스도 싱크도 있다 (`cpguard/specs/py_path_traversal.yml`):

- sources: `request.args`, `request.form`, `request.cookies`, `request.headers`, …
- sinks: `open`, `send_file`, `os.remove`, …

### 미검증 가설 (여기서 세션이 끊김 — 반드시 먼저 검증할 것)

`cpguard/taint/engine.py` 의 **map-get 단축 경로가 소스를 삼키고 있는 것으로 의심된다.**

`_taint()` 의 `ir.Call` 분기에서, 사용자 함수 요약을 보기 **전에** 이 블록이 먼저 돈다:

```python
if cp and "." in cp and node.args:
    recv, _, meth = cp.rpartition(".")
    if meth in _MAP_GET:              # _MAP_GET = ("get", "getOrDefault", ...)
        key = _literal_key(node.args[0], ctx)
        if key is not None:
            hit = _env_lookup(f"{recv}.{key}", env) or _env_lookup(recv, env)
            if hit is None:
                return None           # ← 여기
            ...
```

`request.cookies.get('x')` 는 `recv="request.cookies"`, `meth="get"`, `key="x"` 가 되어
이 분기에 들어간다. `env` 에는 아무것도 없으니 `hit is None` → **`return None`**.
`_matches_source()` 를 한 번도 거치지 못한다.

Flask/Django 는 `request.args.get(...)` · `request.form.get(...)` · `request.cookies.get(...)`
가 표준 관용구다. 이게 맞다면 Python 재현율이 0%대인 이유가 설명된다.

**검증 방법** — 아래를 돌려 1번(`.get()`)만 미탐이고 2번(`[]` 첨자)은 탐지되면 가설 확정:

```powershell
cd C:\dev\cpguard; python -X utf8 -c @'
import tempfile
from pathlib import Path
from cpguard.scanner import scan_file
from cpguard.taint.spec import load_rules
rules = load_rules(user_dir=False)
d = Path(tempfile.mkdtemp())
cases = {
 "1 .get() 소스": "from flask import request\ndef v():\n    bar = request.cookies.get(\"x\")\n    open(bar,\"r\")\n",
 "2 [] 첨자":     "from flask import request\ndef v():\n    bar = request.cookies[\"x\"]\n    open(bar,\"r\")\n",
 "3 속성 직접":   "from flask import request\ndef v():\n    bar = request.data\n    open(bar,\"r\")\n",
}
for name, code in cases.items():
    f = d / (name.split()[0] + ".py"); f.write_text(code, encoding="utf-8")
    print(name, "->", [x.rule_id for x in scan_file(f, rules)] or "미탐")
'@
```

**가설이 맞다면 고칠 위치**: map-get 단축에 들어가기 전에 `_matches_source(cp, ctx.rule)`
를 먼저 보게 한다. 소스로 인정되는 경로면 단축을 타지 않아야 한다. map-get 단축 자체는
`map.put("a", 오염)` 뒤 `map.get("b")` 오탐을 막는 장치이므로 **없애지 말고 순서만** 바꾼다.

**가설이 틀렸다면** 다음 후보: (a) f-string 이 IR 에서 오염 전파로 안 이어짐,
(b) Flask 라우트 데코레이터 안의 중첩 함수 스코프, (c) `import codecs` 후 `codecs.open`
경로가 sink `open` 과 매칭 안 됨(`_callee_matches` 는 `.open` 접미 매칭이라 될 것 같지만 확인 필요).
