Claude (Anthropic) API 키 발급

유료(선불) · 가입 시 초기 무료 크레딧 제공
  1. console.anthropic.com 접속 → 로그인/가입(이메일 또는 Google)
  2. 좌측 Settings → API keys (바로가기: console.anthropic.com/settings/keys)
  3. 우상단 Create Key → 키 이름 입력 → 생성
  4. 키를 복사(한 번만 표시됨) → 위 Claude 칸에 붙여넣고 저장
결제/크레딧을 등록해야 실제 호출이 됩니다(Billing).
가장 쉬운 해결: 키 생성 시 특정 워크스페이스로 제한(Default 등)해서 발급하면 워크스페이스 ID 가 필요 없습니다.
anthropic-workspace-id is required 오류(신원 연동 키)면, 아래 칸에 워크스페이스 ID 를 넣으세요 — 이름(Default)이 아니라 wrkspc_… 형식 ID. Settings → Workspaces 의 ID 열에서 복사합니다.

Gemini (Google) API 키 발급

무료 티어로 바로 사용 가능 — 처음 테스트에 추천
  1. aistudio.google.com/apikey 접속 → Google 계정 로그인
  2. 최초 접속 시 약관 동의 · 지역 확인
  3. Create API key → 새 프로젝트(권장) 또는 기존 프로젝트 선택
  4. 생성된 키 복사 → 위 Gemini 칸에 붙여넣고 저장
결제 등록 없이 무료 티어로 즉시 동작합니다. 트리아지 첫 테스트에 가장 편합니다.

ChatGPT (OpenAI) API 키 발급

선불 결제 필요 — 크레딧 없으면 호출이 실패합니다
  1. platform.openai.com/api-keys 접속 → 로그인
  2. Create new secret key → 이름·권한 선택 → 생성
  3. 키 복사(한 번만 표시됨) → 위 ChatGPT 칸에 붙여넣고 저장
  4. Settings → Billing 에서 카드 등록 + 선불 크레딧 충전($5 이상)
크레딧을 넣지 않으면 rate limit 이 매우 낮거나 호출이 막힙니다. $5 충전 시 Tier 1 로 올라갑니다.
