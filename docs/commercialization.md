# 상용화 로드맵 (아이디어)

CPGuard 를 졸업작품 → 실제 판매 가능한 제품으로 끌어올리기 위한 작업 목록.
우선순위는 대략 위→아래.

## 0. 제품 에디션 전략 (DB 결정과 직결)

| 에디션 | 대상 | DB | 배포 |
|---|---|---|---|
| **Desktop (Local)** | 1인 진단자·컨설턴트 | **SQLite(내장)** | 오프라인 설치본(현재) |
| **Team / Server** | 팀·기업 내부망 | **PostgreSQL** | Docker/서비스, 중앙 서버 + 웹 |
| **CI / SaaS** | DevSecOps 파이프라인 | PostgreSQL(+객체스토리지) | 클라우드/온프렘 |

- PostgreSQL 은 **Team/Server 부터** 도입(동시 다중 사용자·중앙 저장). Desktop 은 SQLite 유지.
- 이미 `CPGUARD_DATABASE_URL` 로 Postgres 전환 가능 → 서버 에디션의 토대는 놓임.

## 1. 정확도 · 엔진 (제품의 핵심 가치)

- **언어 확장**: Java/Kotlin·C#·Go 어댑터(수요 큰 순). 현재 JS/TS/PHP/Python.
- **프레임워크 인지**: Spring·Django·Express·Laravel 의 라우팅/ORM/템플릿을 이해해
  source(요청)·sink(응답/쿼리) 를 정확히 잡기.
- **정확도 벤치마크 공개**: OWASP Benchmark·Juliet·CVE 재현 세트로 정밀도/재현율 수치화.
  상용 SAST 대비 오탐률을 **숫자로** 보여주는 게 세일즈의 핵심.
- **경로/도달성 정밀화**: sanitizer·검증 함수 인식 강화, 프레임워크 미들웨어 반영.

## 2. 확장성 · 성능 (대규모 고객 대응)

- `docs/large-scale.md` 6종(싱크필터·FindingDB·집계API·파싱캐시·멀티프로세스·트리아지클러스터) 완료.
- 다음: **증분 스캔 정식화**(요약 캐시까지), **분산 스캔**(워커 여러 대), **CPG 온디스크**.

## 3. 통합 · 워크플로우 (팀 도입의 관문)

- **CI/CD 통합**: GitHub Actions·GitLab CI·Jenkins 플러그인. PR 코멘트로 신규 취약점 표시,
  기준 미달 시 빌드 실패(SARIF 업로드 → GitHub Code Scanning 연동).
- **이슈 트래커 연동**: Jira·GitHub Issues 자동 티켓 생성(조치 추적).
- **Git 인지**: 커밋·PR 단위 diff 스캔, blame 으로 도입 커밋·담당자 표시.
- **Webhook·API**: 스캔 트리거·결과 조회 REST API 정식화.

## 4. 협업 · 거버넌스 (기업 필수)

- **멀티 유저·RBAC**: 로그인·역할(관리자/진단자/뷰어)·프로젝트 권한.
- **감사 이력**: 누가 언제 무엇을 confirmed/FP 했는지 audit log(규제 대응).
- **정책·베이스라인**: 기존 이슈 baseline, 신규만 게이트, 억제(suppress) 규칙 관리.
- **SSO**: SAML/OIDC(기업 판매 시 요구됨).

## 5. 리포트 · 컴플라이언스 (구매 결정 요인)

- 이미: 진단 결과 보고서·조치 가이드 PDF. 다음:
- **표준 매핑**: OWASP Top 10·CWE Top 25·PCI-DSS·ISO 27001·전자금융감독규정 매핑 리포트.
- **경영진 요약 대시보드**: 추세·위험 점수·조치율 KPI.
- **커스텀 브랜딩**: 고객사 로고·표지 템플릿(컨설팅사 리셀 대응).

## 6. LLM 트리아지 고도화 (차별점)

- **비용 통제**: 클러스터링(완료)·캐시·모델 선택(완료). 다음: 로컬/온프렘 LLM 옵션
  (에어갭 고객은 클라우드 LLM 못 씀 → Ollama·vLLM 연동).
- **근거 신뢰도**: 트리아지 판정에 코드 인용·재현 조건 첨부, 사람 검토 루프.

## 7. 배포 · 운영 · 라이선스 (판매 실무)

- **라이선스 모델**: 좌석/스캔량/코드 규모 기반. 라이선스 키·활성화.
- **자동 업데이트**: 룰·엔진 업데이트 채널(설치본 재배포 대신 델타).
- **Docker/Helm**: 서버 에디션 원클릭 배포. 온프렘 설치 가이드.
- **텔레메트리(옵트인)**: 크래시·성능 리포트(개인정보/코드는 절대 미전송 — 신뢰가 곧 제품).
- **코드 서명**: 설치본 인증서 서명(SmartScreen·백신 신뢰).

## 8. 신뢰 · 보안 (보안 제품의 자기 신뢰)

- 자체 SAST/의존성 감사·SBOM 공개, 취약점 신고 창구(security.txt).
- 스캔 대상 코드·시크릿을 **로컬에서만** 처리(현재 원칙 유지) — 세일즈 포인트로 명문화.
- 3자 침투테스트·인증(가능하면 CREST/공인).
